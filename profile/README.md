# NovaPulse

Plateforme web de gestion de patrimoine pour un cabinet de conseil en gestion
de patrimoine : agrégation des avoirs multi-actifs, indicateurs de performance
et de risque, assistance au rééquilibrage de portefeuille.

| Dépôt | Rôle |
|---|---|
| `NovaPulse-api` | API REST Symfony 7 / API Platform, workers Messenger |
| `NovaPulse-app` | Application web Vue.js 3 / TypeScript |
| `NovaPulse-Infra` | Déploiement, supervision, sauvegardes |
| `NovaPulse-docs` | Architecture, recette, manuels, registre des incidents |
| `.github` | Modèles et workflows communs à l'organisation |

Projet réalisé dans le cadre de la certification RNCP39583 « Expert en
développement logiciel ». Le client Nova Patrimoine SAS est fictif.
